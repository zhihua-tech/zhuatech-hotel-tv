# API 摘要

除健康检查和页面外，请求使用 `x-api-key`；设备可通过 `x-device-token` 进入设备接口。主要接口：`GET /api/dashboard`、`POST /api/properties`、`POST /api/rooms`、`POST /api/devices`、`POST /api/contents`、`POST /api/stays`、`POST /api/service-orders`、`POST /api/playbacks`、`POST /api/broadcasts`。状态流转接口见 `src/server.js`。
